判定依据与已知缺口

  • DLC 安装状态：本机 Steam 已安装 1389240（《西方霸主》）、1557210（《公爵的崛起》）、1869820（《印度王朝》）。《皇家山脉》与《征服与陨落》无对应容器文件，故 亦思马因/索罗斯/塔玛、成王败寇 的文件字段如实标注缺失，未臆造文件名。
  • 洲归属：来自 campaignselection.json 中 Background1–Background8 的卡片分组，与 ButtonContinent1–ButtonContinent8 的材质（ButtonAfricaNormal、ButtonAmericasNormal、ButtonAsiaNormal、ButtonEuropeNormal、ButtonCaucasusNormal 等）一一对应。
  • 界面占位按钮：ButtonContinentParis（IDS_CAMPAIGN_PARIS → 10206「南美洲」）、ButtonContinentPortland（无字符串）、ButtonContinentPeru（IDS_CAMPAIGN_CHINA，无字符串）在本版 UI 中无对应 Background 容器，属预留占位，未纳入表内。
  • 场景中文标题的缺口：只有 34xxx 字符串段按「战役名 + 编号标题」排列，可还原《西方霸主》《公爵的崛起》《印度王朝》的场景名；更早战役该区段存的是场景内势力名（如帖木儿 70901 是「脱脱迷失」），无法据此还原标题，因此对这批战役只给出场景文件名。
